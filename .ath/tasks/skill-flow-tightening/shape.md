# Skill flow tightening

Tighten the `ath` daytime trio and **collapse the overnight path into it**: remove the `night-shift` skill and reconstitute unattended runs from `implement → ship` plus a hook-injected unattended frame.

## What

1. **Unattended frame (hook-driven).** Extend the existing `SessionStart` hook: when `ATH_UNATTENDED` is truthy, inject an unattended addendum to the operating frame. Plugin-wide effect — **no `AskUserQuestion` in an unattended run** (pick the lean, log it), `ship` opens a **draft** PR (no destination question) and **watches it to resolution** — green CI + handled review comments/threads — instead of waiting on a human to stop it; `implement` caps gate retries.
2. **Soft-chain the trio (shape→implement→ship).** Two supervised hand-offs, each a `AskUserQuestion` offer — never a hard chain.
   - **shape gate** gains a third option at "ready": **Build** (invoke `/ath:implement`) · **Build and ship** · **Stop** (today's hand-off). "Build and ship" **pre-authorizes ship for this session** — implement's clean-end offer is then suppressed and it auto-chains to `/ath:ship`.
   - **implement clean end** offers — "ship it now" leading — to continue; accept invokes `/ath:ship`. Unattended, the offer is suppressed and it **auto-chains** to ship(draft). If shape already pre-authorized ship (the "build and ship" path), implement skips the offer and chains directly.
3. **Remove `night-shift`, run a whole brief per routine.** Delete the skill, its `next_task.py`, and its routine-recipe. The overnight behavior is now: one routine run takes **one committed shaped brief (`<slug>`) end-to-end — every unchecked slice → one draft PR** — via `implement → ship(draft)` under the unattended frame. The one-task-per-run model is intentionally dropped; everything else night-shift gave (draft, no-watch, capped retries, no questions) comes from the frame. The routine does **not** run `shape` itself (interactive — needs the human); it consumes a brief the user shaped and committed.
4. **shape self-review unconditional for Medium+.** The fresh-context independent reviewer (shape step 5) runs for Large **and** Medium as the guaranteed final move before the gate; its verdict is surfaced at the gate. Align the stale `draft-first.md` completeness description with step 5.
5. **Document Cloud Routines with this repo (first-class).** A plugin-level `references/routines.md` — a real usage guide, not just a rehomed recipe: when to reach for a routine (cross-ref `scheduling-decision.md`), the never-merge capability-scoping setup, the routine prompt (one `<slug>` → draft PR with `ATH_UNATTENDED=1`), the morning review flow — plus a `scaffold_routine.py` that emits the concrete setup (token scope, `gh` branch-protection commands, the routine prompt, the env var). The README gains a short "run it overnight" pointer to this guide.

## Why

- The trio is hand-off-driven on purpose (you're at the desk); the friction is the _retype_ at each seam — shape→implement and implement→ship. A soft offer at each seam collapses the retype while keeping the human decision at every step (the gate offer, then the ship offer). "Build and ship" lets one nod run the daytime pipeline without surrendering the checkpoints — it just front-loads the ship consent. Never-merge is untouched — `ship` never merges and stops before any protected-branch push. Shaping's "stop and align first" intent survives: the gate is still where alignment is confirmed; chaining only removes the retype after the user said go.
- night-shift ≠ implement+ship only by **one-task + unattended guardrails + draft-stop**. The user chose whole-backlog-per-run, so the one-task differentiator is gone; the rest is more cleanly expressed as a **frame every skill reads** than as a duplicate skill. One source of truth for "how we build / open a PR," reused unattended.
- A frame solves the real unattended hazard generically: an `AskUserQuestion` in a routine hangs forever. Keying it off an env var, injected by the hook, means every skill adapts without per-skill env plumbing — the user's own suggestion.
- The payoff of an overnight routine is **waking to a resolved PR**, not a raw draft sitting on red CI with unaddressed comments — so the unattended path keeps `ship`'s watch (green CI, handle review-bot comments, resolve threads), just bounded by the run budget instead of a human stop. Still draft + never-merge: the run resolves the PR, the human still merges.
- The self-review the user wants already exists in shape step 5 but conditionally; making it unconditional for Medium+ and showing its verdict makes the critique a guarantee the user can _see_, not a claim.

## Design

**The unattended frame is UX/behavior, not the security boundary.** Never-merge is enforced server-side by capability scoping (scoped token, no merge/branch-push, branch protection) — it holds even if `ATH_UNATTENDED` is unset, spoofed, or wrong. The frame only governs interaction (no questions), PR shape (draft), and loop discipline (no watch, capped retries). This separation is load-bearing: the frame must never be the thing standing between the routine and a merge.

- **Hook** (`hooks/inject_operating_context.py` + new `hooks/unattended-context.md`): reads `ATH_UNATTENDED`; truthy → append the unattended addendum to the injected context. Unset/falsy → today's behavior, unchanged.
- **Detection rule:** unattended when `ATH_UNATTENDED` ∈ {`1`,`true`,`yes`} (case-insensitive); anything else (incl. unset, `0`, `false`, empty) = supervised.
- **`ship`**: reads the frame. Unattended → destination is fixed to a **draft PR on a `claude/` branch**, no destination `AskUserQuestion`, then **watch to resolution** — green CI and handle review-bot comments (reply / fix / push to the `claude/` branch / resolve threads), in **two distinct bounded loops**: the existing **CI fix cap (3 cycles, known-flake only)** and a separate **comment-round cap** — a thread the bot re-opens after a fix+reply has been pushed twice halts that thread (it's a bot the run can't satisfy, not a flake), leaving it noted on the draft. The second cap is load-bearing, not hygiene: without it a re-commenting bot that's _right_ burns the budget and ends on a PR whose threads read "replied" but will reopen — worse than a raw draft, and a violation of the "wake to a resolved PR" `why`. Terminates when **resolved (CI green + threads handled)** or the run budget/time is exhausted — never on a human stop. Stays **draft** (never-merge; the human reviews and merges in the morning). Supervised → unchanged (watch is "until you stop it" as today). The watch is **within-run**: comments arriving after the run ends are picked up by the next fire (or an event-triggered routine), not held open across days.
- **`implement`**: step 7 becomes the soft-chain. Supervised + clean → offer; accept → invoke `/ath:ship`. Unattended → skip the offer, auto-invoke `ship`, and cap gate retries at **3, known-flake signatures only**; an unrecoverable failure → stop, open the draft PR with the blocker written into its description, exit (no further slices).
- **`shape`**: step 5 reviewer unconditional Medium+; gate recap gains a one-line reviewer verdict (`reviewer ran: N gaps, all folded / K deferred`). `draft-first.md`'s "when the gray areas run dry" bullet is replaced by a pointer to step 5 (today it describes a stale 2-check pass with no subagent/trace). **Gate becomes a 3-way at "ready"** — Build / Build and ship / Stop. Build → invoke `/ath:implement`; Build and ship → invoke `/ath:implement` and **pre-authorize ship for the session** (a conversational intent, no env var — same "transcript already authorized it" pattern ship uses for irreversible actions); Stop → today's hand-off (save brief + print the command). The "shaping and execution stay separate" language in the SKILL's "Hand off" and `draft-first.md` ("stop at the validated brief / don't roll into it") is reframed: the gate **is** the alignment checkpoint, so an explicit "build" pick is an affirmative start, not a silent roll-through — the no-silent-build intent holds, only the separate-invocation mechanic relaxes.
- **`implement` ← shape pre-auth:** step 7 checks whether ship was pre-authorized this session (the "build and ship" pick). If so → skip the offer, auto-invoke `/ath:ship` (still **only if clean**; a blocked / re-shape run stops and reports, ship does not fire). Else → the normal supervised offer. "Build and ship" authorizes the **chain**, not a destination — ship still runs its Step 1 destination flow (which only asks when signal is ambiguous).
- **Routine scope:** one run = one named brief `<slug>` → all its unchecked slices → one draft PR. If multiple briefs are committed, the routine prompt names which slug; it does not sweep all briefs in one run (that's a separate run / separate PR). The brief and the skills must be committed — the cloud clone sees only git.
- **Routine setup** (`plugins/ath/references/routines.md` + `scripts/scaffold_routine.py`): a usage guide (when-to-use, never-merge scoping, prompt, morning flow) + a script that prints the scoped-token checklist, the `gh` branch-protection commands, the routine prompt (`set ATH_UNATTENDED=1; run /ath:implement against <slug> then /ath:ship`), and the commit-the-brief reminder.

## Behavior

**Happy path (daytime):** `/ath:shape` → gate green → `AskUserQuestion ["Build" | "Build and ship" | "Stop"]`. "Build" → invoke `/ath:implement` → build all unchecked slices → gate green → `AskUserQuestion ["Ship it now" | "Stop here"]` → accept → invoke `/ath:ship`. "Build and ship" → invoke `/ath:implement` (ship pre-authorized) → gate green → auto-chain to `/ath:ship` (no second offer) → ship runs its destination flow.

**Happy path (unattended routine):** routine sets `ATH_UNATTENDED=1` → hook injects the frame → `/ath:implement` builds the whole backlog, capped retries, commits per slice → **auto-chains** to `/ath:ship` (no offer) → ship opens a **draft PR** on a `claude/` branch and stops → human reviews/merges in the morning.

| WHEN                                                                   | THEN                                                                                                                                  |
| ---------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| shape reaches a clean gate (nothing load-bearing open)                 | offer 3-way `["Build" \| "Build and ship" \| "Stop"]`                                                                                 |
| user picks "Build" at the gate                                         | invoke `/ath:implement`; ship not pre-authorized (implement's own offer fires at its clean end)                                       |
| user picks "Build and ship" at the gate                                | invoke `/ath:implement` + pre-authorize ship for the session; implement auto-chains to ship on a clean end                            |
| user picks "Stop" at the gate                                          | save brief, print the exact `/ath:implement` command, end (today's hand-off)                                                          |
| implement finishes clean, supervised, ship pre-authorized this session | skip the offer, auto-invoke `/ath:ship` (destination flow still runs)                                                                 |
| implement finishes clean, supervised, no pre-auth                      | render summary, offer ship (lead "ship it now"); accept → invoke `/ath:ship`; decline → stop + print command                          |
| implement finishes clean, unattended                                   | suppress the offer, auto-invoke `/ath:ship` (draft)                                                                                   |
| implement non-clean (blocked / re-shape valve fires), supervised       | report done/skipped/blocked, **no** offer, point to re-shape                                                                          |
| implement gate fails, unattended                                       | retry ≤3 on known-flake only; unrecoverable → open draft PR with blocker in description, exit                                         |
| any skill would `AskUserQuestion`, unattended                          | do not ask — pick the documented lean, log the choice, proceed                                                                        |
| ship runs unattended                                                   | draft PR on a `claude/` branch, no destination question, then watch to resolution: green CI + handle comments/threads, bounded rounds |
| unattended watch reaches CI green + threads handled                    | resolved — stop the run (don't idle waiting for new comments)                                                                         |
| unattended watch hits persistently-red CI or a re-commenting bot       | halt after the capped rounds, leave the draft PR with the blocker noted, report                                                       |
| new comment arrives after the run ended                                | not held across days — next routine fire (or an event-triggered routine) picks it up                                                  |
| ship runs supervised                                                   | unchanged — destination flow + watch as today                                                                                         |
| `ATH_UNATTENDED` unset / `0` / `false`                                 | supervised everywhere; hook injects only today's frame                                                                                |
| `ATH_UNATTENDED` spoofed but token is merge-capable                    | never-merge still holds — capability scoping + branch protection are server-side, independent of the frame                            |
| shape runs Medium or Large, gray areas dry                             | spawn fresh-context reviewer **always**, last step before gate; show its verdict at the gate                                          |
| shape runs Tiny                                                        | unchanged — shaping skipped, no reviewer                                                                                              |
| routine fires against `<slug>`                                         | build every unchecked slice of that one brief → one draft PR; do not touch other briefs                                               |
| routine fires, brief has no unchecked slices                           | no-op, report "backlog empty for `<slug>`", open no PR                                                                                |

## Out of scope

- One-task-per-run / deterministic single-task selection — _revisit_ if whole-brief PRs prove too big to review.
- A **`/delegate` skill** (auto-pick a brief → `implement` → `ship` → resolved PR, as a single front-door + the thing the routine invokes) — _revisit_ when **multiple briefs queue up**: the auto-select only earns a versioned skill then; with one brief it's premature abstraction over the routine prompt. If added, it picks a whole **brief** (`<slug>`), never a slice — slice-selection is the removed night-shift model and stays out.
- Sweeping **all** committed briefs in one routine run — one run targets one named `<slug>`; _revisit_ if a multi-brief sweep is wanted.
- Cross-day / persistent PR watching — the watch is within-run; an **event-triggered routine** (`pull_request`/comment trigger, per `scheduling-decision.md`) is the way to re-engage on later comments — _revisit_ as a follow-up once the scheduled path lands.
- Hard auto-chain (no offer) in the supervised daytime path — _revisit_ only if the offer is pure friction.
- A general "no AskUserQuestion" mode for arbitrary skills beyond what the frame already covers.
- Changing the never-merge invariant or capability-scoping model.
